HALE-LLM: Autoregressive, Masked Diffusion, Block Diffusion and Flow Matching on One Backbone

Four ways to generate text (next-token, masked diffusion, block diffusion, discrete flow matching) with the same transformer, GPT-2 tokenizer, WikiText-2 pipeline, metrics and experiment tooling.

B A NaveenKumar
Independent research · 2026
Paper (PDF)CodeDocsBlog
TL;DR. Change variant: to switch paradigm. Masks (causal, bidirectional, block-causal), attention (MHA/GQA/MQA), FFN (MLP/GeGLU/MoE) and stack (GPT/LGT/DiT) are config switches. Under a linear masking path, the flow-matching objective equals masked diffusion with time flipped.

Abstract

Masked diffusion and related non-autoregressive language models are credible alternatives to next-token prediction, but published comparisons usually change backbone, tokenizer, data and evaluation at the same time as the objective. HALE-LLM is a controlled testbed in which the paradigm is a plugin and everything else is shared.

It implements autoregressive prediction, absorbing-state masked diffusion with the MDLM ELBO weighting, block diffusion with a block-causal clean/noisy attention mask, and a masking-path discrete flow matching variant, plus a multi-token prediction stub, on a modular decoder library with GPT, Gemma-3-style local–global and DiT stacks. Metrics, per-run experiment folders and unmasking GIFs are shared.

Highlights

Paradigm = plugin

Each of models_autoregressive, _diffusion, _block_diffusion, _flow_matching and _mtp registers a model, collate, loss and sampler. Shared code never imports them.

Masked diffusion

Mask w.p. t ~ U(ε, 1), cross-entropy on masked tokens × 1/t (MDLM ELBO), and reveal sampling with probability (t − s)/t.

Block diffusion

A separate t per 16-token block, [clean ; noisy] input under a block-causal mask, and AR-over-blocks decoding.

Flow matching

Mask w.p. 1 − t with weight 1/(1 − t): identical to masked diffusion under s = 1 − t for this linear path.

Switchable backbone

GPT (47.7M) or LGT with GQA, GeGLU, dual RoPE and time conditioning (63.2M), or DiT with AdaLN-Zero.

Shared tooling

Strict inheritable YAML, timestamped runs with latest, TensorBoard, bits/token, ELBO perplexity, masked accuracy and GIFs.

Quick start

git clone https://github.com/basaanithanaveenkumar/Hale-LLM && cd Hale-LLM
uv sync --extra dev
uv run ha-llm-train --config configs/block_diffusion/small.yaml --no-resume --viz
uv run ha-llm-sample --config configs/block_diffusion/small.yaml
uv run ha-llm-eval   --config configs/block_diffusion/small.yaml
# configs/diffusion/small.yaml
inherits: ../base.yaml
variant: diffusion
model:
  arch: lgt
  attn_type: bidirectional
  attn_impl: gqa
  n_kv_heads: 2
  ffn_type: geglu
  use_time_cond: true
